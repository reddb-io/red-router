## Ordem de execução

### Fase 1 — Migração de branches (git)

1. `git fetch --prune`
2. Criar `main` no mesmo commit de `master`: `git push origin master:refs/heads/main`
3. Definir default: `gh repo edit reddb-io/red-router --default-branch main`
4. Retarget do PR #1: `gh pr edit 1 --base main`
5. Merge do PR #1 **em `main`**: `gh pr merge 1 --merge` (merge commit preserva os 4 commits de feature; mergeável/CLEAN verificado)
6. Apagar `master`: `git push origin --delete master` + local `git branch -d master` (depois de atualizar refs); apagar branch do PR `context-ds-branding` local e remota (merge já absorveu o progresso)
7. Apagar branches dependabot remotas: `git push origin --delete dependabot/github_actions/actions/checkout-7 dependabot/github_actions/actions/setup-node-7`
8. `git remote set-head origin main` e `git fetch --prune`
