The menu hierarchy and the addresses now agree. Free tiers, Rankings and Radar moved from Observe › Costs to Proxy › Providers, next to the Free sources tab; Quota moved from Providers to Observe › Costs; the combo Playground is now "Test combo" and points to Tools › Playground for free-form chat. Addresses say what the page is: `/proxy/keys` (was api-manager), `/optimize/token-saver` with `/engines`, `/combos`, `/studio`, `/exclusions`, `/live` and `/analytics`, `/system/settings/storage`, `/observe/health/runtime` and `/observe/health/connections`, `/observe/logs/conversations` and `/observe/logs/activity`, `/agents/bridge`, `/tools/inspector`, `/system/outbound-proxies`, `/proxy/providers/free-tiers`, `/proxy/providers/rankings`, `/proxy/providers/radar`, `/observe/costs/quota`, `/proxy/combos/test`. Every address ever served, including the ones from the previous release, redirects to the current one in a single hop with the query kept. Internal links across the dashboard (265 across 87 files, plus the CLI hints) now point at the current addresses instead of bouncing through a redirect, and a test fails if a new hard-coded `/dashboard/...` link to a menu page appears. The security model is unchanged: every address is classified as the page it serves before any rule runs, and the embedded-service proxy stays loopback-only.
